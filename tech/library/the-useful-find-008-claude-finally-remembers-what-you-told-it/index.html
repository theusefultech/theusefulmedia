Claude finally remembers what you told it

Chat and Cowork now share one memory, and you can read and edit every line of it

👋 HEY, IT'S RAJA

This is the last quiet Monday for a while. Apple's iPhone event is on Wednesday, September 9, and the rest of this week is going to be nothing but that. So today, something else entirely.

Claude's memory changed a few weeks ago, and it fixed the single most annoying thing about using it for real work.

🔍 The find: Claude's memory, now in one place and readable

Stop re-explaining your own projects every time you open a different part of the app.

What changed

Three things, and they compound.

Chat and Cowork now share one memory. Previously these were separate. You would spend a week developing an idea in chat, then hand the actual work to Cowork and have to explain the entire thing again from scratch. Anthropic merged the two, so what Claude learns in one it keeps in the other. If you have talked through a project in chat, Cowork already knows the names, the numbers, and the constraints when you go to act on it.

Memory saves as you type. It used to wait until a conversation ended and then summarise the whole thing. Now it adds topics as you go, which means a fact you mention at 10am is available in a different part of the app at 10:05 rather than tomorrow.

You can finally read it. This is the part I care about most. Memory used to be one long summary document. It is now a list of short files organised by topic, and you can open any of them and read exactly what Claude thinks it knows about you.

Where to find it

  1. Open Settings.
  2. Go to Capabilities, then Memory.
  3. Click View and manage memory.

You will find two toggles there as well, Search and reference chats and Generate memory from chat history, both on by default. Worth knowing they exist even if you leave them alone.

The bit worth doing today

Go and read it. Not skim it, read it.

Everyone I have suggested this to has found something wrong. A project that ended months ago being treated as current. A preference stated once in frustration and now applied to everything. A company name that changed. One person found something they had only ever typed as a test.

Fix those, and you fix them everywhere at once, because every part of Claude now draws on the same set. Editing is per-item: open the entry, prompt Claude to change or remove it, done.

💡 Pro tip: the fastest way to build a useful memory is to state things deliberately rather than waiting to be noticed. "Remember that I write for an Apple audience and prefer short paragraphs" lands immediately. Automatic memory gets there eventually; telling it directly gets there today.

The catch

A shared, persistent, always-on memory is a genuinely different privacy proposition from a chat that forgets. Anything you mention while thinking out loud can now persist and surface later in a completely different context, including in work you hand off to Cowork.

That is not a reason to avoid it. It is a reason to read the thing occasionally, which is exactly why making it readable was the right call.

💻 Platform: Claude on Mac, web, and iPhone

📍 Where: Settings → Capabilities → Memory

🔄 Works across: chat and Cowork, as one shared memory

✏️ Editable: yes, item by item

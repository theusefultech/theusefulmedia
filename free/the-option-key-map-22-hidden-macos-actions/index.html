Questions

What does holding Option do on a Mac?

It shows a hidden second set of actions in menus, the Dock, Finder and Safari. Hold Option as you click, and items change: Quit becomes Force Quit, Copy becomes Copy as Pathname, and Duplicate becomes Save As.

How do I see Wi-Fi details on a Mac?

Hold Option and click the Wi-Fi icon in the menu bar. Instead of just the list of networks, you get your IP and router address, the security type, the channel and live signal strength.

How do I copy a file path in Finder?

Select the file, hold Option and open the Edit menu. Copy becomes Copy as Pathname, which copies the full path as text for Terminal or a support ticket.

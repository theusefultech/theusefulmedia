Delete your launcher app

macOS Tahoe quietly turned Spotlight into a Raycast rival — set it up in 10 minutes

👋 HEY, IT'S RAJA

Let's start with something every Mac user can do today. For years, the first app I told people to install was a launcher — Raycast or Alfred — because Spotlight was just an app opener. macOS Tahoe quietly changed that.

📘 Delete your launcher app: turn Spotlight into Raycast

macOS Tahoe gave Spotlight its biggest upgrade ever — clipboard history, in-app actions, custom shortcuts. Most people haven't touched any of it. Ten minutes, and yours will be set up.

What you'll need

  • A Mac running macOS Tahoe (macOS 26)
  • About 10 minutes

Step 1 — Turn on clipboard history

This is the big one: your Mac finally has a built-in clipboard manager, but it ships turned off. Go to System Settings → Spotlight and enable Clipboard Search at the bottom. From now on, press ⌘ + Space and then ⌘ + 4 to see everything you've copied in the last 8 hours — text, files, images — ready to paste anywhere. One caveat: it remembers everything, including passwords, so think twice on a shared Mac.

Step 2 — Learn the four modes

Spotlight now has four faces, and switching is instant: with Spotlight open, press ⌘ + 1 for a Launchpad-style app grid, ⌘ + 2 for files, ⌘ + 3 for Actions, and ⌘ + 4 for your clipboard. Muscle-memory these four and you'll stop reaching for the mouse entirely.

Step 3 — Set up Actions and Quick Keys

Actions are where Spotlight becomes a genuine Raycast rival. Press ⌘ + 3 and you'll find tasks you can run without opening any app — send a message, start a timer, create a calendar event, and actions from third-party apps too. Now the power move: select any action and click Add Quick Key to assign it a short trigger of 1–12 letters. Type "gpt" to open ChatGPT, "stimer" to start a timer. Set up five Quick Keys for your most-repeated tasks and feel the difference by Friday.

Step 4 — Search the web (and your tabs) without a browser

Three tricks almost nobody knows: type a site name like Amazon, press Tab, then type your query — Spotlight searches inside that site directly. Your open Safari tabs also show up in Spotlight results, which beats clicking through thirty tabs to find the one. And as you type, filter chips appear under the search field (Folders, Mail, PDFs and so on) — click one, or type "/" to trigger filters from the keyboard.

💡 Pro tip: Spotlight can also run menu commands. Inside any app, open Spotlight and start typing the name of a menu item — no more hunting through nested menus for that one export option.

The result

You now have roughly 90% of a paid launcher, built into your Mac, for free. To be fair to Raycast and Alfred: they still win on text expansion, file operations, and deep customization. But for most people, Tahoe's Spotlight is finally — genuinely — enough.

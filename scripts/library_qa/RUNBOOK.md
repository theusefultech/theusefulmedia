# The Useful Library: daily runbook

The Library lives at theusefulmedia.com/library/. Everything is generated by `scripts/build_library_site.py`
from data files. Never hand-edit files under `library/` that the builder writes.

## Data files
- `scripts/library_problems.py`: problem pages. 1 problem, 3 fixes from 3 different nonfiction books.
- `scripts/library_books.py`: book pages. Every part of the book gets READ, SKIM or SKIP plus a reason.
- `library/game/game.js`: Mystery Book puzzles (`P` list). Puzzle No. 1 is 12 Nov 2026; 1 puzzle per day, in order.
- `library/img/covers/<slug>.webp`: covers, 600px wide, sharp. Source: `https://m.media-amazon.com/images/P/<ISBN-10>.01._SCRMZZZZZZ_.jpg`
  (full size), resized to 600px wide WebP quality 84. Look at every new cover before using it. Wrong edition or blurry = do not ship.

## Daily job: 3 new pages a day
1. Read `scripts/library_problems.py` and `scripts/library_books.py`. Pick the next problem from the `problems` list in the
   builder that has no page yet (status SOON), or a new real problem readers search for in habits, focus, money or mindset.
   Rotate areas so no area gets 2 days in a row.
2. Write 1 problem page entry (3 fixes from 3 books) and a book page entry for each of its books that has no page yet,
   until the day's total reaches 3 new pages. Add the problem to the builder's `problems` list with its url if it isn't there.
3. Quality bar, every line:
   - Every claim must be true to the book. Chapter titles must match the book's real contents: check Open Library
     (`openlibrary.org/books/<edition>.json`, `table_of_contents`) when it has them. If you are not sure of a fact, leave it out.
   - Each fix says what the book argues, 1 thing to try today, and which version of the problem it fits.
   - Book verdicts give a reason for every part. "Read N of M" must match the count of READ units.
   - Voice: short sentences, numerals not words, no em dashes, no hype words, no fiction books.
4. Keep the game 14+ days ahead: if fewer than 14 future puzzles remain, add new ones to `P` in game.js
   (nonfiction only, 6 clues from vague to specific, cover slug only if the cover file exists, otherwise `cover: ""`),
   and add any new title to `EXTRA` only if it is not already an answer.
5. Covers: download and check covers for any new book (see above). Add `{"slug","t","a"}` to `catalog` in the builder.
6. Build: `python3 scripts/build_library_site.py`, then render share images:
   start `python3 -m http.server 8765` in the repo root, run `python3 scripts/render_library_og.py`, quantize the PNGs
   (see the end of this file), rebuild.
7. Wiring: `python3 scripts/site_wiring.py && python3 scripts/seo_pass.py`.
8. QA: `bash scripts/library_qa/run_all.sh` must exit 0. Look at 1 new problem page and 1 new book page screenshot on a
   390px phone width. Fix anything broken before pushing.
9. Commit as `Claude <noreply@anthropic.com>`, then `git fetch origin main && git rebase origin/main && git push origin HEAD:main`.
   GitHub Pages deploys; the SEO workflow pings IndexNow; sitemap and llms.txt are updated by the builder.
10. Verify each new URL returns 200 on theusefulmedia.com after about 90 seconds.
11. Only if something failed after trying to fix it: email Raja what failed and why. Otherwise stay silent.

## When anything is updated
- If a page's content really changes, set `UPDATED["/library/.../"] = "YYYY-MM-DD"` in the builder. Never bump a date without
  a real content change.
- Workers in `workers/` deploy automatically on push (GitHub secret CLOUDFLARE_API_TOKEN).

## Quantize share images
python3 -c "from PIL import Image; import glob; [Image.open(f).convert('RGB').quantize(colors=256,method=Image.Quantize.MEDIANCUT,dither=Image.Dither.FLOYDSTEINBERG).save(f,optimize=True) for f in glob.glob('library/og/*.png')]"

## When a book is added or changed (since 12 Nov 2026)
- Add its 60-second summary and page count to `scripts/library_summaries.py`. The builder needs it.
- Cover: 600px wide or more. Best source is `https://m.media-amazon.com/images/P/<ISBN-10>.01._SCRMZZZZZZ_.jpg`, saved as `library/img/covers/<slug>.webp`. Look at it before committing. Cover URLs carry a content hash, so a new file reaches every visitor without cache problems.
- After the build, run `python3 scripts/render_library_og.py` and `python3 scripts/render_library_cards.py` (share cards in `library/og/card-<slug>.png` and the lead-magnet PDF `library/verdicts.pdf`), then quantize PNGs to 256 colors.
- If you change library.js, library.css or sw.js file caching, bump `V` in `library/sw.js`.
